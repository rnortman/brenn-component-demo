# TODO

Poor man's issue tracker, as brenn's is: an entry here and a `TODO(slug)`
comment at the spot the work happens. The slugs are the join key.

Nothing is outstanding. The entry below is the shape a real one takes — a
template, not a task. Replace it rather than adding beside it.

## `example-slug`

What is wrong or missing, in enough detail that a reader who has not seen the
code can tell whether it still matters. Then why it was deferred rather than
fixed: the reasoning is the part that rots, and the part a later reader needs
in order to reopen the decision.

Where the deferral bites, stated concretely — the wrong behaviour someone
would observe, or the check nothing currently performs. A deferral whose cost
is unstated cannot be prioritised against anything.

Code site (`TODO(example-slug)`): `path/to/file`, at the line the work lands.

Done = the observable condition that retires this entry, written so it can be
checked rather than judged.
